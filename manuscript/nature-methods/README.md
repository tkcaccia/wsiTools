# Nature Methods Submission Package Draft

This folder contains a draft publication package for `wsiTools`.

Files:

- `wsiTools_nature_methods_manuscript.md`: Nature Methods-style manuscript draft.
- `cover_letter.md`: cover letter draft for submission.
- `presubmission_inquiry.md`: shorter presubmission inquiry draft.
- `figure_plan.md`: proposed figures, panels, and data still needed.
- `submission_checklist.md`: practical checklist before submission.

Important: this is not yet ready for direct Nature Methods submission. The tool
needs quantitative validation, benchmark tables, representative datasets,
finalized figures, author details, ethics/data statements, and a tagged software
release with a DOI.
